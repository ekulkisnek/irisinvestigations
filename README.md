# ScreenWarmth

Menu bar app: gamma brightness + blue light on all displays.

## Run

Double-click `ScreenWarmth.app`. First time: right-click → Open if macOS blocks it.

Sun icon in menu bar → sliders → Enable.

## Rebuild

```
./build.sh
```

Requires: macOS 13+, Xcode Command Line Tools (or Xcode). arm64 (Apple Silicon).
